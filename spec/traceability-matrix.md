# Початкова матриця простежуваності

Пункт 12 лабораторної роботи. Матриця охоплює всі функціональні та нефункціональні вимоги поточної версії.

Джерела: [functional-requirements.md](functional-requirements.md), [non-functional-requirements.md](non-functional-requirements.md), [acceptance-criteria.md](acceptance-criteria.md), [given-when-then.md](given-when-then.md). Консолідовані визначення доступні в [SRS.md](SRS.md).

Правила читання:

- ID та короткі назви вимог перенесено з їхніх заголовків без зміни.
- AC наведено за прямим полем «Вимога» критерію; GWT — за прямим полем «Вимоги» сценарію. Зв'язки не виводяться лише зі схожості тексту або непрямих згадок.
- «—» означає, що відповідного прямого зв'язку в джерелі немає. Вимога може мати GWT без окремого AC; це не помилка й не підстава створювати новий критерій.
- Переліки AC та GWT в одному рядку незалежні: вони не означають, що кожен сценарій перевіряє кожен критерій цього рядка. Точні зв'язки GWT–AC наведено в самих сценаріях.
- Ticket, Test, Code і Documentation навмисно залишені порожніми для майбутніх зв'язків; порожні клітинки не засвідчують реалізацію або перевірку.
- Статуси NF-вимог та їхніх критеріїв успадковуються з джерел. Матриця не затверджує запропоновані пороги й не змінює вимоги.
