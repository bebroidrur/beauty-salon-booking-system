# Обраний кодинговий агент

**Кодинговий агент:** OpenAI Codex CLI.

**Клас інструменту:** консольний AI-агент для програмування.

**Робоче середовище:** PyCharm, вбудований Terminal.

**Спосіб доступу до репозиторію:** Codex CLI запускається безпосередньо з кореневого каталогу локального Git-репозиторію `beauty-salon-booking-system`, тому агент може працювати з файлами проєкту в межах робочого середовища.

**Доступні операції:** аналіз структури проєкту та вмісту файлів, створення і редагування файлів програмного коду та документації, виконання команд у робочому середовищі, аналіз результатів виконання коду та підготовка змін для подальшої перевірки засобами Git.

Усі зміни, виконані кодинговим агентом, перевіряються користувачем за допомогою `Git diff` перед їх прийняттям і фіксацією в історії репозиторію.
