- **REQ-NF-004:** пряма погоджена вимога про відсутність зберігання паролів у відкритому вигляді.
- **REQ-NF-005, REQ-NF-007, REQ-NF-008:** погоджена загальна основа; запропоновані конкретні критерії ще потребують погодження.

Числові пороги, профілі навантаження, тестові конфігурації та відповідні умовні AC не стають затвердженими внаслідок SPEC-GATE. Baseline фіксує їх як пропозиції з наявними статусами. Це не підтвердження досягнення показників реалізацією.

## Межі рішення

Специфікація придатна як базова версія для навчального проєкту, подальшого узгодження та планування. Рішення спирається на відсутність blocker і збереження відомих non-blocker; воно не заявляє повної завершеності деталізації або готовності остаточного приймання всіх комбінацій поведінки.

Автоматичних виправлень не виконано. Файли в spec не змінено; нові вимоги, критерії та сценарії не створено. Програмний код не створено, тести реалізації не запускалися. Git commit і фактична фіксація baseline у Git на цьому етапі не виконувалися.
