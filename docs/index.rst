Інформаційна система онлайн-запису до салону краси
====================================================================================================

Документація ЛР6 для фактичного навчального backend: Python, Flask, SQLite
та email-outbox. Є REST API й CLI, графічного інтерфейсу немає.
17 контрактних операцій зареєстровано, ``listSlots`` відсутній;
D-02–D-06 залишаються відкритими обмеженнями, не новими бізнес-правилами.

Python-довідник нижче створює **Sphinx autodoc безпосередньо з модулів**;
Google-style docstrings обробляє Napoleon. HTTP-довідник та інструкція
включені з наявних Markdown-джерел через MyST, без окремих копій тексту.
Команди встановлення, запуску та генерації наведено в README репозиторію.
