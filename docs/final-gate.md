## Суттєві невідповідності

1. Початковий задум і SRS описують адаптивний вебзастосунок, а фактичний результат ЛР5 має REST API та CLI без графічного інтерфейсу.
2. `listSlots` присутній у затвердженому OpenAPI, але не реалізований; два тести пропущені через D-03.
3. Частина часових, reminder і catalog правил має PARTIAL через відкриті D-02–D-06.
4. Нефункціональні UI, browser, TLS, recovery, availability та benchmark-вимоги не підтверджені поточним обсягом.

Ці розбіжності не виправляються зміною SRS, OpenAPI або бізнес-логіки в межах цього етапу. Потрібне рішення людини: прийняти навчальний API/CLI-обсяг як подання лабораторної, погодити addendum/обмеження або повернути цикл на доопрацювання.
