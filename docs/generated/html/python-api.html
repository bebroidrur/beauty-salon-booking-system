Python API з docstrings¶

Сигнатури й описи нижче читаються з коду під час кожної збірки. Імпорт salon.__main__ не запускає CLI завдяки main guard. Історична src.booking не використовується сервером.

salon¶

Beauty salon application.

salon.app¶

Flask adapter for the checked-in OpenAPI contract.

salon.app.create_app(database, clock=None)¶

Create the Flask adapter and initialize its SQLite store.

Параметри:

  • database – Filesystem path to the persistent SQLite database.

  • clock – Optional callable returning an aware datetime; defaults to UTC now.

Повертає:

Flask application with store, clock and service extensions.

Notes

Registers 17 contract operations; listSlots remains blocked by D-03. Request validation and response validation run before transaction commit. This factory does not start an HTTP server.

salon.auth¶

Bearer authentication independent of domain use cases.

salon.auth.authenticate(db, header)¶

Resolve a Bearer session to its stored user.

Параметри:

  • db – Open SQLite connection with row access by name.

  • header – Authorization header text, possibly empty.

Повертає:

User dictionary, including its client or administrator role.

Викликає:

ApiError – With status 401 for a malformed or unknown session token.

salon.service¶

Use cases operating within one SQLite transaction per request.

salon.service.ident()¶

Return a new UUID4 hexadecimal string for an opaque resource ID.

class salon.service.Service(store, clock)¶

Dispatch contract operations within a caller-owned transaction.

This application service is not the catalog’s service entity (a dictionary). Booking mutations and their email outbox changes share the transaction.

__init__(store, clock)¶

Initialize the Store and aware-datetime clock used by booking rules.

get(db, kind, key)¶

Read an entity or reject a missing resource.

Параметри:

  • db – Connection belonging to the caller’s transaction.

  • kind – Stored entity kind: booking, service, master or schedule.

  • key – Entity identifier within that kind.

Повертає:

Decoded entity dictionary.

Викликає:

ApiError – With status 404 when no matching entity exists.

execute(db, op, data, params, user)¶

Dispatch a supported operation after HTTP-level schema and role checks.

Параметри:

  • db – Open SQLite transaction; the caller owns commit and rollback.

  • op – OpenAPI operationId string.

  • data – Validated request body dictionary.

  • params – Validated path and query parameter dictionary.

  • user – Authenticated user dictionary, or None for a public operation.

Повертає:

Contract response dictionary, or None for successful deletion.

Викликає:

ApiError – For missing resources, rejected input, conflicts, bad credentials or unresolved specification decisions in booking/notification rules.

Notes

This is not an independent authorization boundary. listSlots is unsupported.

check_service_ids(db, ids)¶

Check that every identifier in ids references a stored service.

Параметри:

  • db – Open connection used to read service entities.

  • ids – Iterable of service identifiers from a validated request.

Викликає:

ApiError – With status 422 when any service is missing.

Notes

Returns None on success; does not require services to be active.

static check_schedule(value)¶

Validate consistency of a schema-validated schedule dictionary value.

Викликає:

ApiError – With status 422 for duplicate exception dates, incompatible exception kinds or non-increasing working intervals.

Notes

Returns None on success. Existing bookings are checked separately.

salon.booking_service¶

Agreed booking invariants. Unresolved specification cases fail explicitly.

salon.booking_service.unresolved(decision)¶

Reject a case whose specification decision is still open.

Параметри:

decision – Unapproved decision identifier, such as D-02.

Викликає:

ApiError – Always, with status 500 and the decision identifier.

Notes

This guard is not an approved business rule.

class salon.booking_service.Bookings(store, clock)¶

Apply booking invariants within the caller’s SQLite transaction.

The store persists dictionaries; clock supplies aware datetimes. Category current/history is derived from cancellation and calculated end time. Open decisions D-02, D-03, D-05 and D-06 retain explicit rejection guards.

__init__(store, clock)¶

Initialize with a Store and an aware-datetime clock callable.

now()¶

Return the injected clock’s current instant as an aware UTC datetime.

view(value)¶

Return a copy of booking dictionary value with its derived category.

A cancelled booking or one whose endsAt is at or before now is history; all other bookings are current, including those already in progress.

get(db, kind, key)¶

Read an entity or reject a missing resource.

Параметри:

  • db – Connection belonging to the caller’s transaction.

  • kind – Stored entity kind: booking, service, master or schedule.

  • key – Entity identifier within that kind.

Повертає:

Decoded entity dictionary.

Викликає:

ApiError – With status 404 when no matching entity exists.

all(db)¶

Return all stored bookings with categories computed using the clock.

Параметри:

db – Connection belonging to the caller’s transaction.

Повертає:

List of booking dictionaries in storage order, without ownership filtering.

execute(db, op, data, params, user)¶

Execute one of the five supported booking operations.

Параметри:

  • db – Open transaction; the caller owns commit and rollback.

  • op – OpenAPI operationId for listing, creating, reading, updating or cancelling.

  • data – Schema-validated request body dictionary.

  • params – Validated path/query parameters, including category or bookingId.

  • user – Authenticated user dictionary; route role checks run beforehand.

Повертає:

Booking dictionary, or an items dictionary for listBookings.

Викликає:

ApiError – For ownership, missing resources, rule conflicts or open decisions.

Notes

Updates preserve the service snapshot unless the service is replaced. Notification scheduling belongs to Service.execute, not this method.

check(db, value, changing)¶

Validate a candidate booking against time, schedule and overlap rules.

Параметри:

  • db – Open transaction used to read schedules and other bookings.

  • value – Candidate booking with id, clientId, masterId, startsAt and endsAt.

  • changing – Whether an existing booking is being changed; selects error codes.

Викликає:

ApiError – For conflicts, missing schedules or unresolved D-02/D-03 cases.

Notes

Returns None on success. Adjacent intervals do not overlap; cancelled bookings occupy no time. This does not choose a 30-minute grid origin.

static fits(schedule, start, end)¶

Check whether an interval fits the master’s effective working day.

Параметри:

  • schedule – Weekly schedule and dated exceptions from the contract.

  • start – Aware interval start datetime.

  • end – Aware calculated end datetime.

Повертає:

True if the entire nonempty interval fits the working day at start in Kyiv. A matching date exception takes precedence over the weekly schedule.

protect(db, kind, key, operation, data)¶

Reject catalog changes that would invalidate related bookings.

Параметри:

  • db – Open transaction used to read bookings.

  • kind – service or master entity kind.

  • key – Identifier of the entity being changed.

  • operation – Contract operationId for update or delete.

  • data – Validated update body, or an empty dictionary for deletion.

Викликає:

ApiError – For current-booking conflicts or deletion with history (D-06).

Notes

Returns None without mutating stored entities when checks pass.

protect_schedule(db, key, schedule)¶

Reject a schedule that excludes a master’s current bookings.

Параметри:

  • db – Open transaction used to read bookings.

  • key – Master identifier.

  • schedule – Candidate complete schedule dictionary.

Викликає:

ApiError – With status 409 and SCHEDULE_CONFLICT on exclusion.

Notes

Returns None on success; historical bookings do not restrict this check.

salon.store¶

SQLite persistence; each operation owns a connection and a transaction.

class salon.store.Store(path)¶

Persist users, sessions, entities and mail jobs in a SQLite file.

Each transaction opens a connection and uses BEGIN IMMEDIATE, including reads. This serializes writes but is not a production throughput guarantee.

__init__(path)¶

Initialize tables at filesystem path without creating parent directories.

Викликає:

sqlite3.Error – If the database cannot be opened or initialized.

transaction()¶

Open a connection and commit or roll back a serialized transaction.

Yields:

sqlite3.Connection – Connection with sqlite3.Row results and foreign keys on.

Викликає:

  • BaseException – Re-raises failures from the transaction body after rollback.

  • sqlite3.Error – If opening, locking, committing or rolling back fails.

Notes

Uses a 15-second lock timeout and closes the connection after the body.

static get(db, kind, ident)¶

Return the decoded entity for kind and ident, or None if absent.

Параметри:

  • db – Open transaction connection with sqlite3.Row results.

  • kind – Entity kind string.

  • ident – Entity identifier within that kind.

static all(db, kind)¶

Return decoded dictionaries of kind from db in row insertion order.

Параметри:

  • db – Open transaction connection with sqlite3.Row results.

  • kind – Entity kind string; no role or ownership filtering is applied.

static put(db, kind, value)¶

Insert or replace an entity payload without committing.

Параметри:

  • db – Open transaction connection.

  • kind – Entity kind string.

  • value – JSON-serializable dictionary containing its id.

Викликає:

  • KeyError – If value has no id.

  • sqlite3.Error – If the write fails.

Notes

Returns None; callers own validation, commit and rollback.

salon.contract¶

Validation against the unchanged, checked-in OpenAPI contract.

salon.contract.resolve(value)¶

Return a recursively expanded copy of an OpenAPI schema value.

Параметри:

value – Dictionary, list or scalar from the checked-in contract.

Повертає:

Value with local references expanded through the module-level API mapping.

Викликає:

KeyError – If a referenced path does not exist.

Notes

Intended for this contract’s acyclic local references; external references and cycles are not supported.

salon.contract.validate(schema, value)¶

Validate a JSON value using the resolved OpenAPI 3.0 schema.

Параметри:

  • schema – Contract schema, possibly containing local references.

  • value – Decoded JSON value to check.

Викликає:

ValidationError – If value violates the schema or a checked format.

Notes

Returns None on success. Decimal multipleOf uses exact rational arithmetic.

salon.numeric_validation¶

Decimal JSON-schema arithmetic without binary floating-point remainders.

salon.numeric_validation.exact_multiple(validator, divisor, instance, schema)¶

Yield a validation error when a number is not an exact decimal multiple.

Параметри:

  • validator – JSON Schema validator exposing is_type.

  • divisor – multipleOf schema value, converted through its string form.

  • instance – JSON value; nonnumeric values are ignored by this keyword.

  • schema – Enclosing schema, accepted for the validator callback interface.

Yields:

ValidationError – If the ratio is nonintegral or cannot be calculated.

salon.time_rules¶

Canonical conversion of instants to salon time.

salon.time_rules.instant(value)¶

Parse an ISO datetime string value and return an aware UTC datetime.

Викликає:

ValueError – If value is not a parseable ISO datetime string.

Notes

API callers must supply an explicit offset as required by the contract. A naive value follows Python’s host-local timezone conversion behavior.

salon.time_rules.local(value)¶

Return aware datetime value as an ISO string in Europe/Kyiv.

Naive inputs follow the host-local timezone; API callers supply aware values.

Store status (HTTP integer), code and message (strings).

Raise a structured API error without changing persistent state.

Викликає:

salon.events¶

Allowlisted diagnostic events: never serialize request or exception objects.

salon.events.record(operation, status, request_id, code=None)¶

Emit one allowlisted JSON diagnostic event at INFO level.

Параметри:

  • operation – Safe operation name, never a URL or request body.

  • status – Numeric HTTP-style result status.

  • request_id – Correlation identifier for the request or mail job.

  • code – Optional safe error code; defaults to None.

Notes

Returns None. Callers supply safe values; this function does not redact arbitrary strings and must not receive secrets or personal data.

salon.notifications¶

Transactional email outbox; no network side effects before commit.

salon.notifications.enqueue(db, booking, kind, due)¶

Insert a pending email job in the caller’s transaction.

Параметри:

  • db – Open connection containing the booking’s registered client.

  • booking – Booking dictionary to snapshot in the mail payload.

  • kind – Notification kind understood by build_message.

  • due – Aware datetime at which the job becomes eligible for delivery.

Notes

Returns None. Reads the client’s email and stores it with the booking; does not commit or send mail. Storage errors propagate to the caller.

salon.notifications.on_booking(db, before, after, now)¶

Schedule notifications for a successful booking mutation.

Параметри:

  • db – Same open transaction as the booking mutation.

  • before – Previous booking dictionary, or None when creating.

  • after – Saved booking dictionary with its current details.

  • now – Aware datetime used for immediate delivery and reminder eligibility.

Викликає:

ApiError – For unresolved D-04 when moving a booking without an earlier reminder to a start at least 24 hours away.

Notes

Returns None. Cancels obsolete reminders and snapshots updated details. The caller must roll back the booking and outbox together on failure.

salon.mail_worker¶

Durable due-job delivery; failures remain visible for explicit retry.

salon.mail_worker.run_once(store, clock, transport)¶

Deliver pending mail whose due time has arrived in one transaction.

Параметри:

  • store – Store providing a SQLite transaction.

  • clock – Callable returning an aware datetime for the due-time cutoff.

  • transport – Object with send(kind, payload) that delivers one message.

Повертає:

Number of messages successfully handed to the transport in this pass.

Notes

Transport exceptions mark jobs failed and are not propagated. Failed jobs are not automatically retried. The transaction remains locked during I/O; a crash after SMTP acceptance and before commit can duplicate delivery. Storage errors propagate to the caller.

class salon.mail_worker.SMTPTransport(host, port, sender, starttls=True, username=None, password=None)¶

Deliver outbox messages over SMTP with optional STARTTLS and login.

__init__(host, port, sender, starttls=True, username=None, password=None)¶

Store SMTP connection settings without opening a connection.

Параметри:

  • host – SMTP hostname.

  • port – SMTP TCP port integer.

  • sender – From address used for generated messages.

  • starttls – Whether to negotiate STARTTLS; defaults to True.

  • username – Optional login username.

  • password – Optional login password, used when username is supplied.

send(kind, payload)¶

Send a notification using a new SMTP connection with a 10s timeout.

Параметри:

  • kind – created, changed, cancelled or reminder notification kind.

  • payload – Dictionary with to and booking, as persisted in the outbox.

Викликає:

  • SMTPException – If negotiation, authentication or delivery fails.

  • OSError – If the network connection fails.

Notes

Returns None on success; does not update the outbox state itself.

salon.mail_worker.build_message(sender, kind, payload)¶

Build a plain-text notification from the persisted booking snapshot.

Параметри:

  • sender – From email address.

  • kind – created, changed, cancelled or reminder.

  • payload – Dictionary with to and a booking containing serviceSnapshot.

Повертає:

EmailMessage with Ukrainian subject and booking details; no network I/O.

Викликає:

KeyError – If kind is unknown or a required payload field is missing.

salon.__main__¶

Local development server, administrator provisioning and email worker.

class salon.__main__.SafeRequestHandler(request, client_address, server)¶

Suppress Werkzeug access lines that could disclose query personal data.

log_request(code='-', size='-')¶

Ignore code and size supplied by Werkzeug and return None.

Application events provide the allowlisted request diagnostics instead.

salon.__main__.main()¶

Run the development server, admin provisioning or outbox worker CLI.

Reads process arguments and SMTP environment variables; provisioning prompts for profile and password. Returns None when a finite command completes. The server and worker without –once run until interrupted.

Викликає:

  • SystemExit – For argparse help or invalid command-line arguments.

  • KeyError – If required SMTP environment settings are absent.

  • ValidationError – If the administrator profile violates the contract.

  • sqlite3.Error – If database initialization or provisioning fails.

src.booking.create_booking(client_name, service, master, time)¶

Return the historical four-field booking dictionary without validation.

Параметри:

Повертає:

Dictionary with the original client, service, master and time values.
