# Критичний шлях і ресурсний ланцюг — лабораторна робота №3

**Актуалізація, пункт 17 (2026-10-14):** розділи 1–7 збережено як аналіз **B0**. Наприкінці наведено нові прямий/зворотний проходи й резерви **S2 із додатковими Gate**; старі резерви не перенесено автоматично. Дата повного NF-приймання невідома.

**Статус: аналіз плану, не виконання робіт.** Дата аналізу: 2026-10-12. Джерела: [implementation-plan.md](implementation-plan.md) і [gantt.md](gantt.md); охоплено всі **45 D-тікетів**.

**Основний результат:** логічний критичний шлях за відомими залежностями плану має **31,75 робочого дня**. Додавання планового зв’язку D-40 → D-41 з Ганта збільшує його до **34,75 дня**. За фіксованим порядком двох потоків AI та одного Human календарний ресурсно-критичний ланцюг має **42,5 робочого дня**, до **2026-12-16 13:00 Europe/Kyiv**. Це кінець резервованого графіка; повне приймання не має підтвердженої дати через невизначену NF-гілку.

## 1. Модель розрахунку та межі точності

Використано базові оцінки, уже обрані в Ганті: 60,5 дня сумарного активного завантаження, з них 36,25 AI та 24,25 Human. Календар — від 2026-10-19, понеділок–п’ятниця, 09:00–17:00; один крок розрахунку — **2 години = 0,25 робочого дня**. Вихідні й нічні години не додають активної тривалості.

Побудовано три моделі:

| Модель | Ребра та тривалості | Для чого потрібна |
| --- | --- | --- |
| L — логічна за implementation-plan | Відомі залежності П/З/У; тривалість тікета = AI + нормативне очікування + Human. Без ресурсних черг і без додаткового D-40 → D-41. | Показує, що визначають самі відомі роботи й погодження. |
| G — логічна за нормалізацією Ганта | Та сама модель з передумовами таблиці Ганта, включно з D-40 → D-41. | Відділяє вплив додаткової послідовності від впливу ресурсів. |
| R — ресурсна для наявного календаря | Кожен тікет поділено на A (AI), W (обов’язкове очікування, якщо є) та H (Human). Додано ребра між послідовними роботами одного AI-потоку і між усіма послідовними H-сесіями в порядку Ганта. | Визначає резерви при збереженні поточного розподілу та порядку ресурсів. |

Як і в Ганті, залежності «блокує закриття» консервативно трактуються як завершення перед початком залежної роботи. Умовні уточнення включено для повного пакета. Це **нормалізований CPM**, а не оптимізація часткового старту пакетів. Зв’язки інтеграції «І» не перетворюються на зворотні блокування. Після переходу до дозволених ранніх часткових стартів потрібен новий розрахунок.

У L/G нормативне очікування становить 1 день для кожного Addendum/Gate та 1,5 дня перед Validation. Ресурсна черга з Ганта **не додається** до цих тривалостей: у R вона виникає через зайнятість ресурсу. Це запобігає подвійному обліку черги.

Алгоритм: прямий прохід `ES = max(EF передумов)`, `EF = ES + тривалість`; зворотний прохід `LF = min(LS наступників)`, `LS = LF − тривалість`; повний резерв `TF = LS − ES`. Для R відлік зворотного проходу ведеться від кінця календарної бази — 16 грудня, 13:00. Розраховані ранні старти **всіх A/W/H-відрізків точно відтворили дати Ганта**: додаткові довільні обмеження дат для цього не знадобилися.

Точність наведених резервів — точність цієї дискретної моделі відомих робіт. Вона не враховує невідомі NF Test/Feature, повторні відмови на Gate, нові ітерації виправлень, свята чи відпустки. Переупорядкування рецензій або перенесення роботи на інший AI-потік змінить ресурсні резерви. Вони не є «вільними днями», які всі задачі можуть одночасно використати.

## 2. Логічний критичний шлях

### 2.1. Залежності плану реалізації — модель L

```text
D-01 → D-45 → D-11 → D-14 → D-15 → D-17 → D-19 → D-21 → D-23 → D-27 → D-29 → D-33 → D-37 → D-39 → D-40 → D-42 → D-43 → D-44
```

Тривалість — **31,75 робочого дня**; умовний ранній кінець за необмеженого доступу до ресурсів — **2026-12-01 15:00**. Усі наведені в цьому ланцюгу 18 тікетів мають нульовий логічний резерв у L.

Це математична нижня межа для відомих робіт, **не здійсненний розклад для одного Human**. Наприклад, паралельні рецензії Addendum у такій моделі не обмежені спільним рецензентом. D-41 не входить до цього шляху, бо у плані немає обов’язкового ребра D-40 → D-41: за відомою частиною він міг би закінчитися раніше. Його великий формальний резерв **не означає**, що невідомі NF-роботи можна вважати виконаними.

### 2.2. Логічний шлях із додатковою послідовністю Ганта — модель G

```text
D-01 → D-45 → D-11 → D-14 → D-15 → D-17 → D-19 → D-21 → D-23 → D-27 → D-29 → D-33 → D-37 → D-39 → D-40 → D-41 → D-42 → D-43 → D-44
```

Тривалість — **34,75 дня**, ранній кінець — **2026-12-04 15:00**. Тут нульовий логічний резерв мають ті самі 18 тікетів і додатково D-41. Різниця **3 дні** є наслідком планового послідовного розміщення D-41 після D-40, а не наслідком нестачі рецензентів.

До кінця D-40 обидві логічні моделі збігаються: **25,5 дня**, **2026-11-23 13:00**. У ресурсному графіку D-40 закінчується **2026-12-03 11:00**, через **33,25 робочого дня** від старту. Це окрема контрольна точка перед умовним завершальним блоком.

## 3. Ресурсно-критичний ланцюг календарного графіка

**A** — AI-частина; **H** — перегляд/рішення Human; **W** — нормативне очікування. Одному D-ID можуть відповідати різні резерви A та H. Наступні стрілки позначають також порядок спільного ресурсу, а не лише залежності предметної області.

Один із чотирьох рівнодовгих критичних маршрутів R:

```text
D-01:A → D-02:A → D-02:W → D-02:H → D-03:H → D-45:H → D-04:H → D-05:H → D-06:H → D-08:H → D-09:H → D-10:H → D-11:H → D-14:A → D-14:H → D-16:H → D-18:H → D-20:H → D-24:H → D-22:H → D-15:H → D-26:H → D-28:H → D-32:H → D-30:H → D-25:H → D-36:H → D-38:H → D-17:H → D-19:A → D-19:H → D-21:A → D-21:H → D-23:A → D-23:H → D-27:A → D-27:H → D-29:A → D-29:H → D-33:A → D-33:H → D-37:A → D-37:H → D-39:A → D-39:H → D-40:A → D-40:H → D-41:A → D-41:H → D-42:W → D-42:H → D-43:A → D-43:H → D-44:W → D-44:H
```

Якщо згорнути послідовні частини одного тікета, послідовність критичних D-ID цього маршруту така:

```text
D-01 → D-02 → D-03 → D-45 → D-04 → D-05 → D-06 → D-08 → D-09 → D-10 → D-11 → D-14 → D-16 → D-18 → D-20 → D-24 → D-22 → D-15 → D-26 → D-28 → D-32 → D-30 → D-25 → D-36 → D-38 → D-17 → D-19 → D-21 → D-23 → D-27 → D-29 → D-33 → D-37 → D-39 → D-40 → D-41 → D-42 → D-43 → D-44
```

Цей маршрут не охоплює всі нульові відрізки: після D-17:H до D-21:H є **чотири рівнодовгі розгалуження**:

```text
D-17:H → D-19:A → D-19:H → D-21:A → D-21:H
D-17:H → D-34:H → D-12:H → D-19:H → D-21:A → D-21:H
D-17:H → D-19:A → D-13:A → D-13:H → D-21:H
D-17:H → D-34:H → D-12:H → D-13:A → D-13:H → D-21:H
```

Тому D-12, D-13 та D-34 також ресурсно критичні, хоча їх немає в першому наведеному маршруті. D-13:A чекає попередньої роботи AI-1, а D-19:H / D-21:H — попередніх Human-сесій. Це зв’язки конкретного розкладу; вони не додають нових залежностей до SRS.

Різниця G → R становить **7,75 робочого дня**. Загальна різниця L → R — **10,75 дня = 3 дні додаткової послідовності NF + 7,75 дня ресурсних обмежень**. Не слід називати всі 10,75 дня «затримкою Human»: ресурсні ребра включають також послідовність AI-потоків і взаємодію обох типів ресурсу.

## 5. Вузькі місця та затримки людського перегляду

**Основне вузьке місце ранньої частини — послідовний Human.** За календарем D-11 має 1 день нормативного очікування та ще 2 дні ресурсної черги. Надалі критичний маршрут проходить через багато H-сесій, у тому числі задач із великим логічним резервом. Найдовші окремі черги до Human — по 3 дні в D-12 і D-36; для D-34 — 2,75 дня, для D-30/D-38 — 2,5 дня. Це вже закладені черги, а не додаткові тривалості понад графік.

Другий обмежувач — залежний ланцюг **D-19 → D-21 → D-23 → D-27 → D-29 → D-33 → D-37 → D-39 → D-40**. Після завершення ранньої черги він обмежує корисну паралельність: сам по собі вільний другий AI-потік не усуває необхідні результати попередніх задач. Усі активні A/H-відрізки цього ланцюга мають нульовий резерв у R.

Нижче наведено окремі сценарії подовження **однієї H-сесії на 1 робочий день** зі збереженням порядку ресурсів, тривалостей решти задач і залежностей. Це моделювання чутливості, не фактичні затримки; результати різних рядків не додаються автоматично.

Ніхто не вважає погодження отриманим після спливу цього часу. За реального перепланування можна переглянути порядок інших сесій, але це вже інший ресурсний графік.

Практичні рекомендації, що не змінюють поточні документи:

1. Заздалегідь захистити слот Human для D-11 і критичних переглядів ланцюга запису. Переглянути доцільність порядку D-08–D-10 перед D-11: це кандидат на оптимізацію, а не доведена кількість зекономлених днів.
2. Готувати матеріали до рецензії повністю й об’єднувати уточнення на одному перегляді там, де це не змінює критеріїв. Не скорочувати заплановані H-сесії просто через швидке виконання AI.
3. Не намагатися прискорити лише логічно критичні Feature: некритичні за L задачі D-12/D-13/D-34 можуть зсунути весь календар через ресурсні ребра.
4. Після будь-якої зміни порядку переглядів або додавання NF-задач перебудувати граф і перевірити завантаження обох AI-потоків та одного Human. Поточні резерви після такої зміни не переносяться механічно.

## 6. Невизначена NF-гілка та що неможливо обчислити точно

D-41–D-44 — **умовні резерви**, не роботи з доведеною готовністю всіх передумов. У розрахунку не створено нульових фіктивних NF Test/Feature і не припущено їх виконання до старту. Числа в моделях описують лише відому частину графа без відсутніх вузлів.

Для фактичного повного погодженого обсягу зараз **неможливо точно визначити**:

- справжній критичний шлях через NF-реалізацію та випробування;
- кінцевий строк PASS для D-41–D-44 і резерви щодо цього строку;
- загальну додаткову потребу в AI/Human та вплив її конкуренції з уже запланованими задачами;
- вплив прийняття місячного спостереження REQ-NF-011, поки не визначені погодження, готовність середовища й дата початку вікна.

Навіть 20 днів формального `TF L` для D-41 не є бюджетом невідомої NF-гілки. Після її деталізації вона може стати новим критичним шляхом або збільшити чергу Human. Відкладення конкретного критерію не скасовує погоджених основ захисту персональних даних, адаптивності й браузерної сумісності.

## 7. Контроль розрахунку та висновок

Перевірено 45 унікальних D-ID, їхні базові тривалості й залежності. Єдина різниця відомих ребер між L та G — додане в Ганті D-40 → D-41. Для R окремо відновлено порядок кожного AI-потоку та Human за часовими вікнами, підтверджено відсутність накладань ресурсу й точний збіг усіх розрахованих ранніх стартів із календарем. Виконано прямий/зворотний проходи, знайдено чотири рівнодовгі ресурсні критичні маршрути та розраховано чутливість до окремих затримок H/W. Це перевірки моделі планування, не тести продукту або приймання.

**Висновок:** контролювати треба одночасно логічний ланцюг створення/зміни запису та ресурсну чергу Human. За незмінного розкладу 42 із 45 тікетів містять хоча б одну частину з нульовим резервом; це чутливий до затримок календар. **16 грудня 2026 року, 13:00** лишається кінцем умовного резервованого сценарію, а не гарантованою датою завершення всього погодженого обсягу.
