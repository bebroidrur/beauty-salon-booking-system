# Workflow — життєвий цикл задач

## Статуси GitHub Project

- **Todo** — задача сформована, але робота ще не почалася.
- **In Progress** — виконавець працює над задачею.
- **In Review** — результат очікує перевірки.
- **Done** — результат перевірено та прийнято.

## Діаграма переходів

```mermaid
flowchart LR
    A["Todo"] -->|"Human: призначення та дозвіл"| B["In Progress"]
    B -->|"AI або Human: передача результату"| C["In Review"]
    C -->|"Human: приймання"| D["Done"]
    C -->|"Human: зауваження"| B
    B -->|"Human: скасування або перепланування"| A

## Розподіл відповідальності

| Перехід | Відповідальний | Умова |
|---|---|---|
| Todo → In Progress | Human | Дозвіл розпочати задачу |
| In Progress → In Review | AI / Human | Результат готовий до перевірки |
| In Review → Done | Human | Критерії приймання виконано |
| In Review → In Progress | Human | Потрібне доопрацювання |
| In Progress → Todo | Human | Перепланування задачі |

## Правило контролю

AI може створювати код, тести та документацію, але остаточне приймання результату виконує Human.
