# Конвенція повідомлень комітів

У проєкті використовуються такі префікси повідомлень комітів:

- `spec:` — зміни специфікації та вимог;
- `test:` — зміни тестів;
- `feat:` — зміни функціональності або структури проєкту;
- `docs:` — зміни документації;
- `gate:` — контрольні рішення та результати перевірки стану репозиторію.

Префікс повинен однозначно відображати тип артефакту або дію, виконану в межах SDD-процесу.
